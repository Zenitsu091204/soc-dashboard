PROJECT MODULES
Last Updated: 2026-02-24 | v3.2.0
====================================

1. CORE INFRASTRUCTURE

   Authentication Module
   - File:    client/src/context/AuthContext.js
   - File:    client/src/pages/LoginPage.js
   - File:    server/controllers/authController.js
   - File:    server/middleware/authMiddleware.js
   - File:    server/utils/generateToken.js
   - Purpose: End-to-end JWT authentication. LoginPage submits credentials to
              POST /api/auth/login. On success, token stored in localStorage.
              AuthContext wraps the app, exposes useAuth() hook, listens for
              the custom auth:unauthorized event (dispatched by Axios on 401)
              and handles logout + SPA redirect via React Router navigate().
              Server-side: authMiddleware verifies JWT on protected routes;
              admin middleware gates admin-only endpoints.
   - v3.2.0:  Role hardening — self-registration always assigns 'analyst' role.

   Layout Module
   - File:    client/src/layout/SOCLayout.js
   - Purpose: Collapsible sidebar navigation, top header with GlobalSearch
              and user info, and main content area with scroll management.

   Theme Module
   - File:    client/src/theme.js
   - Purpose: MUI dark theme configuration — glassmorphism design tokens,
              consistent colour palette (indigo/cyan/violet/amber/emerald),
              typography scale, and component overrides.

   API Service Module
   - File:    client/src/services/api.js
   - Purpose: Centralised Axios instance. Request interceptor: auto-attaches
              Authorization: Bearer <token>. Response interceptor: on 401,
              clears localStorage/sessionStorage and dispatches a custom
              auth:unauthorized CustomEvent so AuthContext (not the HTTP layer)
              owns the redirect — avoids full page reload.
   - Base URL: reads REACT_APP_API_URL env var (fallback: localhost:5000).

   Global Search Module
   - File:    client/src/components/GlobalSearch.js
   - Purpose: Ctrl+K / Cmd+K application-wide modal search across Alerts,
              IOCs, and Threat Actors. Data fetched once per dialog open and
              cached in useRef (not per keystroke). AbortController cancels
              previous in-flight requests when query changes or dialog closes.
              Cache cleared on dialog close for fresh data on next open.


2. DASHBOARD & VISUALISATION

   Overview / Live Monitor
   - File:    client/src/pages/OverviewPage.js
   - Purpose: Primary monitoring dashboard. Fetches alerts from /api/alerts
              and stats from /api/alerts/stats. Displays KPI cards, severity
              snapshot, alerts trend, alert status breakdown, recent activity

              Confidence calculation is memoised (useMemo). Inline error banner
              with Retry shown on API failure.

6. BACKEND API

   Alert Module (server)
   - File:    server/controllers/alertController.js
   - File:    server/routes/alertRoutes.js
   - Routes:  GET  /api/alerts           — all alerts (auth required)
              POST /api/alerts           — create alert (admin only)
              GET  /api/alerts/stats     — aggregate stats (auth required)
              PATCH /api/alerts/:id      — update status (404 on unknown ID)
   - v3.2.0:  Prisma P2025 error caught and returned as 404 Not Found.

   Auth Module (server)
   - File:    server/controllers/authController.js
   - File:    server/routes/authRoutes.js
   - Routes:  POST /api/auth/register    — create analyst account (public)
              POST /api/auth/login       — returns JWT token (public)
              GET  /api/auth/profile     — authenticated user profile (private)
   - v3.2.0:  Role field removed from registration body; always 'analyst'.

   Intel Module (server)
   - File:    server/controllers/intelController.js
   - File:    server/routes/intelRoutes.js
   - Routes:  GET /api/intel/threat-actors  — ordered by lastSeen desc
              GET /api/intel/iocs           — ordered by seenAt desc

   Database Module
   - File:    server/prisma/schema.prisma

   - Purpose: Prisma ORM with PostgreSQL. Singleton PrismaClient reused

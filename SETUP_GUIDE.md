# 🛡️ SOC Dashboard — Setup Guide

---

## 🐧 Ubuntu / Linux Setup (Recommended)

Use the all-in-one bootstrap script. It handles:
- Installing Node.js 20 and PostgreSQL
- Fixing PostgreSQL authentication
- Fixing Windows CRLF line endings
- Installing all npm dependencies
- Running database migrations and seeding
- Launching the app

```bash
chmod +x setup-ubuntu.sh
./setup-ubuntu.sh
```

*(Frontend → http://localhost:8000 | Backend → http://localhost:8001)*

---

## 🪟 Windows Setup

Double-click `setup.bat`, or run in PowerShell:

```powershell
node setup.js
```

*(Frontend → http://localhost:3000 | Backend → http://localhost:5000)*

---

## 🚀 Production Deployment (Unified Server — any OS)

No need for two processes. The Express backend statically serves the React bundle.

```bash
# 1. Build the frontend
cd client
npm run build

# 2. Start the unified server
cd ../server
node index.js
```

*(Full application → http://localhost:8001)*

## 🐘 Manual PostgreSQL Setup (Ubuntu)

If the automated script cannot configure PostgreSQL, do it manually:

```bash
# Start PostgreSQL
sudo systemctl start postgresql
sudo systemctl enable postgresql

# Set password and create database
sudo -u postgres psql -c "ALTER USER postgres WITH PASSWORD 'postgres';"
sudo -u postgres psql -c "CREATE DATABASE soc_dashboard;"

# Fix authentication: change peer → md5
sudo nano /etc/postgresql/*/main/pg_hba.conf
# Find this line:
#   local   all   postgres   peer
# Change it to:
#   local   all   postgres   md5

# Restart to apply
sudo systemctl restart postgresql

# Verify connection
psql -U postgres -h localhost -d soc_dashboard -c "\l"
```

## 🔑 Environment Variables

`server/.env` is auto-generated by the setup script. If generated manually, copy `.env.example`:

```bash
cp server/.env.example server/.env
```

Then edit `server/.env` and set a strong `JWT_SECRET`:
```bash
node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
```

## 🆘 Troubleshooting

| Error | Cause | Fix |
|-------|-------|-----|
| `P1000 Authentication failed` | PostgreSQL peer auth | Follow Manual PostgreSQL Setup above |
| `error:0308010C` (OpenSSL) | Node 17+ + old webpack | `export NODE_OPTIONS=--openssl-legacy-provider` |
| `npm install` peer dep errors | React 19 conflicts | `npm install --legacy-peer-deps` |
| `EADDRINUSE :8001` | Port already in use | `sudo kill -9 $(sudo lsof -ti :8001)` |
| App unreachable from browser | UFW firewall blocking | `sudo ufw allow 8001 && sudo ufw allow 8000` |
